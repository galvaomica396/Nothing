## 개인정보 보호 조건

- 원본은 사용자 다운로드 위치에서 읽기 전용으로 사용했다.
- 원본 파일명, 전체 경로, 원문, 검출 값, 좌표는 이 문서와 저장소에 기록하지 않았다.
- 분석 산출물은 메모리에서 집계한 뒤 폐기했고, 원본 또는 마스킹 PDF를 저장소에 복사하지 않았다.
- 아래 SHA-256은 입력 동일성 확인용이며 문서 내용 대신 사용할 수 없다.

## 판정

네 문서는 모두 예외 없이 분석되었고 분석 리비전은 1이었다. 공개문서 경계는 근거가 충분하지 않은 항목을 자동 확정하지 않고 전부 검토 대기로 유지했다. 검토를 생략한 저장 또는 최종화는 허용되지 않으므로 이 실행에서는 실제 문서의 출력 PDF를 만들지 않았다.

합성 네이티브 시나리오는 별도의 패키지 영수증에서 사람 검토 해결, 수동 결합, 원본 변조 차단, 저장 대상 권한, 원자적 승격 실패 차단과 최종 승격을 검증한다. 실제 문서 QA는 원문 노출 없이 입력 적합성과 fail-closed 분석 동작을 검증하는 역할만 담당한다.

## 알려진 비차단 관찰

추출 중 PyMuPDF의 구형 `fitz` import 경고가 출력되지만 현재 분석 결과에는 영향을 주지 않았다. 의존성 변경 없이 기존 추출 폴백을 유지했으며, 향후 PyMuPDF 메이저 업데이트 전 `pymupdf` import 경로 전환을 별도 점검해야 한다.
